# Verify One Complete Track Before Expanding

The first playable slice will be one complete 60-90 second generated track using a 3x3 block grid, eight cut directions, score, combo, misses, restart, and no fail state. This keeps the project focused on proving mouse-controlled slicing, readable chart pacing, and score quality before adding bombs, walls, uploads, multiple songs, or fail-state pressure that could obscure whether the core saber loop actually works.
