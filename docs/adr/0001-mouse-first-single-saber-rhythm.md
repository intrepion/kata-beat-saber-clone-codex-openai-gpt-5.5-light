# Mouse-First Single-Saber Rhythm

The game will be a recognizable browser rhythm-slicing clone built around one mouse-controlled saber, a 3D-feeling neon tunnel, beat blocks approaching a strike plane, and cut judgments based on both position and direction. This deliberately rejects a normal two-saber or VR-first design: the mouse is not a fallback input, it is the core instrument, so charts, scoring, and feel must be tuned around one expressive blade rather than a missing second hand.
